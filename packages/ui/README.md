# vueduck UI

Vue 3 & Nuxt component library. Plain CSS themed with `--vd-*` CSS variables.

## Vue

```ts
import VueDuck from 'vueduck-ui'
import 'vueduck-ui/style.css'

createApp(App).use(VueDuck)
// or: import { VdButton } from 'vueduck-ui'
```

## Nuxt

```ts
export default defineNuxtConfig({ modules: ['vueduck-ui/nuxt'] })
```
